# 等待界面参考与素材

界面布局及粒子视觉参考 `hydro-dev/xcpc-tools` 的 `PresentationPage.tsx`、`ParticleBackground.tsx` 和 `style.css`，固定提交为 `cfb5cc8a7c4df82c29be6354adf2997b5f9258c6`。WCCS 采用 Rust / Win32 绘制，使用现有身份与等待控制协议。[上游源码](https://github.com/hydro-dev/xcpc-tools/tree/cfb5cc8a7c4df82c29be6354adf2997b5f9258c6/packages/machine-tools/frontend/src)
