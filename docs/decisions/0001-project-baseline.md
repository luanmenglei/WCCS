# ADR 0001 项目基线与初始技术方向

日期为 2026-11-10。状态为架构基线保留，初始技术选型已由 [ADR 0002](0002-linux-rust-stack.md) 替代。

## 背景

系统需支持 200～300 台 Windows 10 机器，教学时服务器离线，比赛使用现有账户。IP 可作为座位分配入口，系统复原和 D 盘清理构成赛后恢复方式。当前仓库处于初始化阶段。

## 决定

- 单仓库维护服务器、Windows 服务、会话界面、竞赛命令、Web 界面和模拟客户端。
- 单体服务器集中管理持久状态，客户端主动建立控制连接，文件数据使用独立传输通道。
- Windows 服务处理特权操作，会话程序处理等待界面和用户环境。IPC 显式授权。
- IP 用于匹配座位，设备注册、控制命令与管理员操作建立独立认证。
- 教学模式支持服务器长期关闭；有效比赛安排在本地支持短期断网运行。
- 基础程序和服务器信任配置纳入镜像；D 盘承载可清理的比赛数据。复原后重新注册并核对服务器状态。
- P2P 使用可信文件清单、分块校验、受限节点列表与回源下载；现场网络允许时启用互传。
- Codex 以根 AGENTS.md、路线图和可执行检查驱动逐项交付，任务内完成实现、验证、自审与状态记录。

## 初始技术选型历史

| 部分 | 初始化时的方向 | 当时列出的验证条件 |
| --- | --- | --- |
| Windows 服务与 CLI | C# / .NET，服务使用 Worker 模式 | Q-01、Q-02，目标系统运行时兼容性及离线部署验证 |
| 会话程序 | C# / WPF | 多屏、DPI、快捷键、会话生命周期原型 |
| 服务器 | ASP.NET Core 单体 | Q-06，鉴权、长连接及持久任务原型 |
| 控制连接 | HTTPS + SignalR | 自动重连、消息边界、旧版本兼容、峰值同步验证 |
| 数据库 | PostgreSQL | 服务器部署条件、备份恢复及批量任务事务验证 |
| Web UI | TypeScript，框架在首个 Web 切片选择 | 座位图增量刷新、权限交互、离线资源打包 |
| 文件传输 | HTTPS 分块下载，增加受控 HTTP(S) P2P | Q-04，授权、校验、回源和吞吐演练 |

上述选型记录初始化时的建议。用户随后明确 Linux 服务端和 C++/Rust 原生客户端方向，当前工程按 ADR 0002 推进，首个应用工程引入时提交工具链版本、依赖锁定与构建入口。

## 影响与复查条件

模拟客户端和纯状态逻辑可先行验证。Windows 登录、策略、界面与复原行为需要真实环境证据。P2P 的收益取决于交换机、跨机房链路及允许的通信范围。

当实际 Windows 版本限制运行时、网络无法支持机间互传、服务端部署条件变化或容量测试出现瓶颈时，更新本 ADR 或追加替代决策，并关联证据。
