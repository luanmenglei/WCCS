# ADR 0008 M2 比赛名单与座位分配

日期为 2026-11-10。状态为已实施，开发机与现场证据边界见 [任务记录](../tasks/m2-participant-seating.md)。

## 背景

沿用 Natsume 固定基线 `9b2dca59cf2cd4358c02bc051e318da44cda85e4` 的 Preparation、名单差异、座位映射与提交时复核流程。已核对 preparation-page、preparation-diff、import/roster 和 import/commit 实现。上游声明 AGPL-3.0-or-later，本轮使用 WCCS 既有依赖独立实现 Windows 单人竞赛流程。[参考实现](https://github.com/4o3F/Natsume/tree/9b2dca59cf2cd4358c02bc051e318da44cda85e4)

## 决定

- PostgreSQL 版本 4 增加比赛、选手、分配和不可变操作结果。兼容版本 1～3，已有设备、座位、配置、任务、凭据历史及请求记录继续保留。
- 最小比赛上下文为稳定 ID、名称、版本和创建时间。管理员显式选择比赛，页面顶部的同一选择用于名单、座位和设备详情。新登录及刷新后显式重选。创建比赛不会启用比赛安排，时间与运行策略继续在 M3 实施。
- 每场最多 500 名选手，本切片最多保存 100 场比赛。选手稳定 ID 属于单场参赛记录，参赛标识在场内唯一、区分大小写、保留前导零。同一标识在另一场具有不同稳定身份。跨场自然人身份合并与账号同步需独立设计。
- 首次导入用比赛 ID、规范化参赛标识和比赛基准版本派生稳定 ID，预览和提交一致。修改参赛标识继续保留原 ID，后来导入旧标识会创建新的参赛记录。禁止凭姓名或学校自动合并身份。
- 首版格式为 UTF-8 TSV，可含文件首 BOM，接受 LF/CRLF。精确表头为 `code`、`name`、`school`，三列按制表符分隔。字段去首尾 Unicode 空白，保留内部空格、中文和前导零。空白行忽略，字段必填，限制分别为 80、100、200 个 Unicode 字符。禁止控制字符、无效编码替换字符、引号转义及多行字段。
- 导入按场内参赛标识 upsert，缺失行保留。空学校或姓名属于错误，清空资料需后续明确需求。预览逐行列出新增、修改、冲突及未变化，任一错误整批拒绝。重复内容使用新请求提交时生成新的审计版本，稳定身份和分配保持相同；同一请求重试返回原结果且不新增版本或审计。
- 分配仅关联比赛、选手稳定 ID 和座位稳定 ID。数据库复合外键保证同场归属，唯一约束保证同场每名选手及每个座位最多一个有效分配。不同场次可安排同一座位。
- 自动分配只处理未分配选手，按参赛标识 UTF-8 字节顺序、机房稳定 ID 字节顺序及座位显示编号递增执行。固定所选机房，保留已有分配。无 IP、未注册和离线座位允许提前安排，冲突或匹配禁用设备的座位跳过，容量不足整批拒绝。手动新分配遵循同一禁用/冲突约束，已存在的分配可保留或解除。
- 手动调整可同时提交多个选手，交换在一个事务内完成。界面选择已占座位时明确预览双方变化，当前选手未分配时原占座选手变为未分配。解除后保留资料及历史。
- 重编号保留分配。缩减机房涉及任一场次已分配座位时，预览和提交均拒绝，提示比赛及参赛标识，管理员先到对应比赛调整或解除。移除后重建位置获得新座位 ID。历史结果保存操作时的座位名称、编号、位置及选手资料快照。
- 设备禁用保留 IP 占用与选手计划。撤销释放设备占用，选手仍属于原座位。重新授权、地址核对或换设备后，设备详情通过当前 IP 匹配显示座位选手。冲突设备显示座位计划及冲突标签，地址待核对单独标识。换座位必须显式修改选手分配。
- 所有本切片管理写入复用 Cookie、Origin、CSRF 和单管理员鉴权。创建使用比赛列表基准版本，其余操作使用比赛基准版本；配置头行锁统一串行化设备观察、机房和名单事务。预览摘要覆盖输入、原名单、计划及当前机房/地址/生命周期/在线状态，提交重新计算。线上状态变化也要求重新预览。
- 请求内容、请求编号、结果和审计同事务保存。重试先查去重结果，同编号不同内容返回 409。事务中断整体回滚。历史按比赛和递减游标每次最多 50 条，可核对请求编号及前后变化。普通日志只记录错误类别，凭据沿用现有脱敏规则。

## 影响与重新评估条件

历史场次和操作结果持续保留，当前没有删除入口。历史资料可由显式选场修正并留下新版本。若需归档只读、跨场身份、名单删除、学校字典、随机分配、同校避让、超过 100 场或长期保留策略，分别扩展数据模型和验收。

本轮沿用单连接与完整快照轮询，300 座位长期运行及多场历史容量需 M6 实测。当前全机房状态纳入预览摘要，其他机房的设备状态变化也可能要求重做预览。实际 Linux、HTTPS、跨 VLAN 和 Windows 10 复原镜像条件按原环境清单补齐。
