# ADR 0014：本机诊断、展示数据与固定维护任务

状态：实现已接入，原生与部署验收按任务记录逐项补齐。日期：2026-11-12。

## 背景

machine-tools 对齐需要工作人员本机入口、设备健康、完整等待展示及桌面准备。既有 WCCS 已具有设备凭据、IP 座位绑定、SCM/会话 IPC、单调控制租约、请求去重、权限及事件事务。继续复用这些边界。

## 决定

- 连接配置与设备凭据分离。版本 1 文本/文件格式可离线保存，配置摘要和修订号绑定设备身份；目标网卡按索引及 MAC 再核验。座位声明只提供核对材料，服务端 IP 绑定与换机流程保持权威。
- 本机诊断采用实际 SCM、鉴权 IPC、HTTP、独立 WSS 探针回执。诊断探针不替换控制连接。固定字段报告与白名单关联日志可脱敏导出，失败项保留最近成功时间和恢复说明。
- 健康与展示使用独立工作线程。健康约 30 秒一次，慢采集不追赶积压；失败保留最新样本。控制续租不等待这些线程的网络请求或采集结果。管理员看到数据来源、采集时间和过期状态。
- 展示按比赛版本化。时间样本与 RTT 仅用于显示，倒计时按单调启动计时推进，不能授予或续延控制。DOMjudge 使用客户端真实 HTTP 适配器；未配置、认证要求和连接失败明确区分。
- 校徽采用有界 24 位 BMP，与 SHA-256、学校及来源一起通过认证数据通道交付。缓存包含比赛、设备、座位、身份版本及来源；缓存诊断可离线读取。重启不凭缓存进入比赛控制，新的命令身份必须重新匹配。
- 固定维护模板为设备识别、桌面入口、普通账户目录检查和脚本包部署。模板参数、维护配置和工具配置版本进入预览摘要，提交重新检查；服务端保存不可变命令并给出逐机结果和事件关联。
- 工具路径仍由服务端完整配置。桌面操作在 SYSTEM 服务执行，但桌面位置由真实普通账户令牌解析，访问验证使用该账户令牌。目录逐级拒绝重解析点，持有目录句柄，脚本根目录拒绝普通账户写入。
- 小型 UTF-8 脚本包独立打包，限制 64 文件/128 KiB，含来源、许可、解释器工具 ID 和 PE 文件版本。不可变版本目录校验完成后最后写入 active.json。暂不执行任意远程 Shell；选手命令契约和 DOMjudge 提交继续属于 M3。
- 执行前写入任务与文件旧值日志，原子替换并读回核验。结果先持久化、收到精确 ACK 后标记已确认，完成日志保留用于拒绝重复副作用。重启核验已提交内容；未提交文件回退。遇到外部修改保留现场，阻止后续维护，修复冲突后重试恢复。
- 用户会话子进程先挂起创建，加入禁止脱离的 Job Object 后运行。Job 关闭或停止时清理进程树。固定任务没有任意命令输出；参数、文件和步骤结果均有上限。

## 兼容、限制与重新评估

数据库顺序增加迁移 008～012。诊断/健康/维护/展示为独立新增接口；旧客户端不声明新能力时跳过任务。inventory 新字段可选。展示 IPC 字段可选，新宿主与会话程序应成套更新，旧会话程序拒绝未知字段时安全失败，不降级绕过鉴权。

文件修改在每一步及最终提交前检查授权和 60 秒单调期限。Windows 同步文件系统调用本身不能被这个检查强制中断；设备驱动或文件系统永久挂起属于仍需独立故障验证的限制。实际 SCM、普通账户桌面、Job Object 子进程树和系统重启结果以独立 Windows 测试为准。

本机管理员仍可修改文件、停止服务或改变系统策略，ACL 和目录句柄不能推导出对管理员的绝对防干预保证。发生外部改变时优先保留数据并报告恢复冲突。

超过小包限额、需要二进制资料分发、任意脚本执行或并行任务时，重新评估 M3/M4 的分发、进程隔离与激活边界，不扩大现有模板的隐式权限。

实现入口、验证命令及剩余环境条件见 [对齐记录](../tasks/machine-tools-alignment.md)。
