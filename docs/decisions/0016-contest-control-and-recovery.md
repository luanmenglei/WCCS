# ADR 0016 比赛联动、HTTPS 分发与赛后恢复

日期为 2026-11-17，状态为已采用，原生现场验收继续待补。

## 决策

用户选择 DOMjudge 9.0.2、一个 judgehost，并要求暂停同时作用于评测和桌面。使用独立 API 账户和固定源码扩展，WCCS 保存持久安排、预览范围、身份代次与操作员版本。暂停和结束先关闭提交，开始和恢复等待全部所选桌面解除回执。断线重连、权限或目标变化、服务重启使旧安排失效，工作人员重新预览。

DOMjudge 扩展使用 RemovedInterval 保存暂停区间，冻结时间并顺延结束等未来里程碑。暂停时原生 end_time 使用 2100 年内部占位，扩展状态接口返回冻结剩余时间。原生 CLICS 比赛时长扣除暂停区间，外部计时消费者需接入扩展状态。固定版本与原文件摘要校验、原件备份、PHP 语法检查和安装回退集中于 integrations/domjudge。

按用户决定取消 P2P。HTTPS 资料和源代码归档使用 256 KiB SHA-256 分块，持久数据放入 PostgreSQL，随数据库备份。资料下载并发上限 16，归档 ZIP 生成并发上限 2。新增 zip 9.6.0，仅使用 Stored 写入，不引入压缩功能，用于可直接下载的标准归档。依赖固定在 Cargo.lock。

赛后恢复复用 maintenance 的权限、预览、会话确认、持久命令及回执，顺序为检查、归档或明确跳过、教学恢复、清理、重启、重新检查。前一步成功记录冻结目录、卷身份、文件及散列，原生客户端再次核验。重解析点、系统卷整卷清理、客户端自身目录和范围变化均拒绝。只清理确认清单，清理中断保留部分完成事实，后续需要新检查。

一次检查限制 4096 个文件与目录、总内容 512 MiB，限制同时覆盖待归档与待清理文件，避免扫描和服务端内存无界增长。整卷模式排除回收站和 System Volume Information。更大规模需容量测试后另行调整。

比赛策略采用系统级可移动存储 Deny_All 与 LSA 软件关机权限。先保存恢复记录再应用，记录绑定当前机器。关机策略保留 SYSTEM 和 Administrators，恢复原普通用户权限持有者。离线恢复、教学恢复和镜像封装共同调用既有恢复链。默认不启用这两项，管理员在受控登录预览中选择。

重启结果首先表示系统已接受请求，新的连接、心跳启动时间和教学状态用于观察重启。复原后的文件内容通过新检查确认。模拟入口仅写独立目录与重启标记。

## 验证与边界

Windows/Linux 构建、数据库、前端、临时目录端到端和实际 DOMjudge 联调已通过。现场策略、重启、整盘复原与正式容量仍待验，见 docs/tasks/m3-m5-implementation.md。DOMjudge 自身网页在内置浏览器超时，暂停时钟可视验证待补。当前提供单机验收材料。

## 软件关机权限恢复边界

Windows 用户权限分配在下一次登录生效。恢复 LSA 授权后，旧比赛会话令牌仍需重新登录才能获得关机权限。当前离线恢复保留程序与文件，教学管理员账户可正常使用。旧比赛会话原地恢复全部电源能力尚未完成，M5 该项继续待补，现场先保持软件关机选项关闭。实施完整恢复需补充受控本机电源入口或经确认的重新登录流程，当前包不把它计入已通过实机项。[Microsoft 用户权限说明](https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-10/security/threat-protection/security-policy-settings/shut-down-the-system)
