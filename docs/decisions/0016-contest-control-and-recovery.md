# ADR 0016 比赛联动、HTTPS 分发与赛后恢复

日期为 2026-11-17，状态为已采用，原生现场验收继续待补。

## 决策

用户选择 DOMjudge 9.0.2、一个 judgehost，并要求暂停同时作用于评测和桌面。使用独立 API 账户和固定源码扩展，WCCS 保存持久安排、预览范围、身份代次与操作员版本。暂停和结束先关闭提交，开始和恢复等待全部所选桌面解除回执。断线重连、权限或目标变化、服务重启使旧安排失效，工作人员重新预览。

DOMjudge 扩展使用 RemovedInterval 保存暂停区间，冻结时间并顺延结束等未来里程碑。暂停时原生 end_time 使用 2100 年内部占位，扩展状态接口返回冻结剩余时间。原生 CLICS 比赛时长扣除暂停区间，外部计时消费者需接入扩展状态。固定版本与原文件摘要校验、原件备份、PHP 语法检查和安装回退集中于 integrations/domjudge。

按用户决定取消 P2P。HTTPS 资料和源代码归档使用 256 KiB SHA-256 分块，持久数据放入 PostgreSQL，随数据库备份。资料下载并发上限 16，归档 ZIP 生成并发上限 2。新增 zip 9.6.0，仅使用 Stored 写入，不引入压缩功能，用于可直接下载的标准归档。依赖固定在 Cargo.lock。

赛后恢复复用 maintenance 的权限、预览、会话确认、持久命令及回执，顺序为检查、归档或明确跳过、教学恢复、清理、重启、重新检查。前一步成功记录冻结目录、卷身份、文件及散列，原生客户端再次核验。重解析点、系统卷整卷清理、客户端自身目录和范围变化均拒绝。只清理确认清单，清理中断保留部分完成事实，后续需要新检查。

旧版恢复任务限制 4096 项、总内容 512 MiB。2026-11-17 增加 recovery-v2，数量可配置到 100000 项，清理总字节数不限，选定源文件的归档容量可配置到 512 MiB，执行时限可配置到 24 小时。旧任务和旧客户端按原能力处理，扩展任务使用独立日志目录。整卷模式排除回收站和 System Volume Information，详细边界见 [稳定性记录](../tasks/client-deployment-stability.md)。

比赛策略采用系统级可移动存储 Deny_All 与 LSA 软件关机权限。先保存恢复记录再应用，记录绑定当前机器。关机策略保留 SYSTEM 和 Administrators，恢复原普通用户权限持有者。离线恢复、教学恢复和镜像封装共同调用既有恢复链。默认不启用这两项，管理员在受控登录预览中选择。

重启结果首先表示系统已接受请求，新的连接、心跳启动时间和教学状态用于观察重启。复原后的文件内容通过新检查确认。模拟入口仅写独立目录与重启标记。

## 管理操作范围（schema 20）

同一服务端上的 WCCS 比赛与评测比赛一对一显式绑定；账号同步和比赛控制共用该配置，等待展示的公开 API 来源仍单独设置。按已有权限和请求号记录绑定操作。改绑时检查正在执行的任务、未解除的暂停和仍在使用的账号绑定。

暂停在发出远端写操作前持久记录本次座位。失败时保留可能受影响的范围；后续开始、恢复或结束必须覆盖全部未结座位，只有成功完成才在任务落库的同一事务中清除。其目的在于避免局部桌面释放却恢复全场计时，不改变断线退出控制的规则。现场操作及升级限制见[管理员操作走查](../tasks/admin-workflows.md)。

## 验证与边界

Windows/Linux 构建、数据库、前端、临时目录端到端和实际 DOMjudge 联调已通过。现场策略、重启、整盘复原与正式容量仍待验，见 docs/tasks/m3-m5-implementation.md。DOMjudge 自身网页在内置浏览器超时，暂停时钟可视验证待补。当前提供单机验收材料。

## 软件关机权限恢复边界

Windows 用户权限分配在下一次登录生效，已有令牌无法补回缺失权限。本轮选择本机受控电源入口，教学和策略恢复成功后由服务核验比赛账户 SID 及活动控制台会话，允许显式关机或重启。桌面准备发布对应快捷方式，保留原会话即可使用，Windows 原生电源菜单在下次登录恢复。代码、鉴权与现场验证边界见 [稳定性记录](../tasks/client-deployment-stability.md)。[Microsoft 令牌说明](https://learn.microsoft.com/en-us/windows/win32/secbp/changing-privileges-in-a-token)

## 2026-11-18 修订

比赛暂停沿用原控制连接，以短租约维持桌面，客户端单调时钟到期、断线或替换连接后需要重新授权。旧客户端在暂停预览中标记为需要升级。解绑座位后可单独撤销评测账号的 IP 和会话，也可与新席位同步同批执行。资料分发在发布前领取服务端授权，领取后进入发布中，禁止再提交取消。

整卷操作须在新版客户端核对部署设备与 D 盘的卷 GUID、序列号，并与本轮检查清单一致。恢复历史按比赛查询并按需读取清单。分块上传和摘要核验独立于控制写连接，核验完成后重新核对授权。重启成功回执、客户端记录的请求号、同一设备代次的新宿主及匹配的启动时段、教学状态共同确定首次观察时间。维护回执确认后压缩保存，无法补报的永久拒绝和损坏记录保存在隔离目录。
