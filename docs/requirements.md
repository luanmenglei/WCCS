# 需求基线

更新日期为 2026-11-10。来源为项目初始化讨论及其后对 Linux 服务端、原生客户端和管理界面的要求。

## 已确认的现场条件

| 编号 | 条件 |
| --- | --- |
| ENV-01 | 多机房、Windows 10、单人算法竞赛，约 200～300 台机器，硬件配置较好 |
| ENV-02 | 信息中心屏蔽外网和机房电脑之间的通信 |
| ENV-03 | 机房兼顾普通教学，教学时 WCCS 服务器通常关闭 |
| ENV-04 | 复原软件恢复 D 盘以外的分区，D 盘数据保留 |
| ENV-05 | 用户允许赛后清空 D 盘并统一重启，信息中心可以协助预装客户端 |
| ENV-06 | 比赛期间 IP 基本稳定，有志愿者协助核对，需处理少量地址变化 |
| ENV-07 | 安装客户端时服务器 IP 尚未确定 |
| ENV-08 | 服务端部署在 Linux，用户建议采用 Node.js、Rust 或 Go 等技术 |
| ENV-09 | Windows 客户端采用 C++ 或 Rust 的原生实现方向，用户关注性能和安全 |

## 功能范围

| 编号 | 功能 | 可观察结果 |
| --- | --- | --- |
| REQ-01 | 教学与比赛模式 | 服务器关闭时教学正常；明确启用比赛后执行有效安排 |
| REQ-02 | 现有账户与统一登录 | 沿用现有 Windows 用户，统一进入比赛环境；Windows 登录方式单独验证 |
| REQ-03 | 座位与选手 | 服务端维护机房、座位、IP、姓名、学校及比赛关联，支持现场识别和换机 |
| REQ-04 | DOMjudge 集成 | 绑定 IP 自动登录，验证地址变化、旧绑定撤销和来源地址可见性 |
| REQ-05 | 竞赛命令 | compilecpp 提供一致的编译入口；submit 返回可核对的提交结果 |
| REQ-06 | 健康与事件 | 自动检查编译环境和连通性，上报在线状态、设备变化和执行失败 |
| REQ-07 | 设备与电源限制 | 比赛期间限制未授权设备使用及软件关机，支持志愿者处理外设故障 |
| REQ-08 | 比赛等待界面 | 展示姓名、学校、座位号，触碰鼠标键盘给出提示，支持统一开放与结束 |
| REQ-09 | 桌面准备 | 保留指定编程软件、DOMjudge 与 tech notes 入口 |
| REQ-10 | 文件分发 | 按机房或机器下发文件，显示下载、校验、发布结果，支持断点续传及 P2P |
| REQ-11 | Web 管理 | 授权人员从其他机器的浏览器操作，包含机房座位图、选手分配、比赛控制、文件分发、告警、任务进度和权限管理页面 |
| REQ-12 | 赛后恢复 | 按比赛收集策略处理代码，清空部署目标 D 盘、重启并确认复原 |

## 设计建议与范围约定

- 服务器采用单体部署，Windows 服务与用户会话程序分工，详见架构及 ADR。
- 在用户给出的语言范围内，当前项目方向选择两端 Rust，管理界面使用 React + TypeScript + Vite。此实现选择及后续验证条件见 ADR 0002。
- 500 个模拟客户端用于容量余量验证，该数字为项目设计目标。
- 文件收集是赛后流程的可配置步骤；每场比赛明确收集范围或选择跳过，并记录结果。
- 统一资料下发满足当前资料需求。内部资料站可在后续实际需求出现时评估。
- P2P 所需机间通信与 ENV-02 的网络隔离需要现场协调。服务器直接下载始终可用。
- 自动恢复教学的时刻及离线恢复规则需要比赛配置明确，比赛结束和恢复教学分别管理。

## 待验证事项

| 编号 | 未知项 | 获取方式及影响 |
| --- | --- | --- |
| Q-01 | Windows 版本、版本号、架构 | 只读采集；影响运行时和系统 API 兼容性 |
| Q-02 | 当前账户类型、权限和登录方式 | 信息中心确认并采集；影响自动登录和权限限制 |
| Q-03 | 复原产品、复原时机及系统设置覆盖范围 | 测试镜像重启演练；影响策略、凭据和任务恢复 |
| Q-04 | DNS、跨 VLAN 路由、P2P 放行能力 | 网络拓扑与端口测试；影响发现和分发方式 |
| Q-05 | DOMjudge 版本、API 认证及代理配置 | 测试实例联调；影响登录、提交和换机 |
| Q-06 | Linux 发行版、CPU 架构、服务器配置及部署方式 | 部署方确认；影响二进制兼容、打包、容量测量和存储安排 |
| Q-07 | 比赛延时、暂停与教学恢复时间规则 | 比赛运行配置；影响离线计划和状态转换 |
| Q-08 | D 盘卷标识、容量及目录重解析点 | 只读采集与测试卷演练；影响清理和重新注册 |

未知项按各自依赖阻塞具体功能，其余开发可继续使用明确标识的模拟适配器与合成数据。
