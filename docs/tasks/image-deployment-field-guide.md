# 机房镜像准备现场说明

本轮 Windows 部署排除 503-41。具体流程、目标机器以及是否采用下述镜像方案均待确定。已发出的 503-41 专用 ZIP 绑定旧机器，请勿用于本轮部署。

以下步骤适用于已选用统一镜像、且母机已有可升级的 WCCS 安装的情况。目标确定后，按该机的 Windows 计算机名和 MachineGuid 重新制作专用包。客户端、运行时、公开 CA、配置和两份手册随包交付。

## 母机工作人员

1. 解压到工作人员材料目录。核对当前 Windows 计算机名和 MachineGuid 与新包内 `mother-target.json` 的目标一致，保存正在编辑的文件。以管理员运行 `01-upgrade-mother.cmd`，等待成功。它会升级原安装，并将统一镜像载荷放到 `C:\Program Files\WCCS-Image`。
2. 在管理页面的比赛账户中预览这台母机。确实可以结束教学会话后勾选确认，执行准备登录。等待普通比赛账户进入桌面，首次欢迎或系统设置由工作人员完成。新版本会等待活动桌面和 Windows Shell 回执。
3. 在批量维护中执行桌面准备、工作目录检查和脚本部署，核对实际工具能打开。随后在比赛账户页面恢复教学，切回教学账户，保存比赛账户中的测试工作。
4. 以管理员运行 `02-seal-mother.cmd`。工具先恢复教学，检查账户所有权、普通权限、恢复账户凭据、真实桌面准备记录和用户配置文件，再导出账户模板。它会移除母机 WCCS 服务和 Provider 注册，清除已核对的 WCCS 安装目录及启动身份目录中的逐机材料，安装克隆启动任务。
5. 清理母机上以前传入的**单机注册材料、旧测试压缩包和原始诊断目录**，包括桌面、下载目录、回收站及工作人员另存的副本。这些外部副本可能包含旧设备凭据，封装工具只负责自身安装和启动状态目录。当前交付包的公开配置和代码可以保留。
6. 在信息中心的镜像工具中保存整盘测试镜像，分发到选定的两台代表机。封装成功后应直接关机捕获，下一次正常启动会生成这台机器自己的运行材料。如果母机已正常启动过，应重新完成封装再捕获。

封装会一并保留当前安装中的旧公共工具运行时，服务器已有工具路径可以继续使用。

账户模板包括本地账户 SID、所有权和受 Windows DPAPI 保护的登录材料，保存在仅管理员与 SYSTEM 可读的目录。它依赖本次完整系统镜像中的 SAM、用户配置文件和系统密钥。对镜像额外执行 Sysprep、重建 SID 或清理用户配置文件后，需要重新验证模板导入。

## 分发后自动完成的工作

- 从各台 Windows 系统读取其实际计算机名。
- 按机器名关联服务端设备编号，生成本轮独立随机凭据，安装客户端并建立机器信任。
- 核对镜像中的普通比赛账户与已初始化配置文件，导入账户模板并安装受控登录组件。
- 向服务器申请接入。服务器关闭或注册窗口关闭时等待，教学账户保持可用。
- C 盘整盘复原后重新执行上述流程，同一机器名继续关联原设备记录。

常规克隆部署无需逐台编辑 JSON、复制注册令牌或初始化普通账户。镜像配置调整由管理员在母机统一处理。

## 管理端工作人员

1. 打开注册窗口，在“注册审核”的“镜像设备与复原后接入”列表核对机器名和本次来源 IP。
2. 勾选本轮申请，确认更新凭据，批准所选设备。同名多份申请需核对并拒绝错误申请，原设备仍在线时先处理重名问题。
3. 按已有座位核对流程确认 IP 与座位。第一次从原单机安装切换镜像身份时，使用已有换机/绑定入口把座位关联到新镜像设备，旧记录保留。以后同名镜像设备的凭据更新保留原记录和座位计划，地址变动需要核对。
4. 赛前在比赛账户页面批量准备登录，核对真实桌面成功，再执行所需维护模板。退出教学会话仍须确认工作已保存。
5. 普通账户准备完成后恢复教学，比赛正式开始时再下发新的登录或等待操作。

全盘复原后的接入批准是本轮凭据授权。比赛控制仍由单独的明确管理操作启用。

## 失败与恢复

- 注册列表显示客户端初始化失败时，在目标机查看 `C:\Program Files\WCCS-Image-State\status.json`，其中记录失败阶段。保留该文件回传。修复条件后可由工作人员启动任务计划程序中的 `WCCS-Image-Bootstrap` 重试。
- 母机操作失败可运行 `03-diagnose.cmd` 导出既有脱敏诊断，或运行 `04-recover-teaching.cmd` 恢复教学。封装已删除原安装后，恢复入口会报告安装不存在，此时教学账户已在封装前恢复。
- 克隆机可在管理员终端运行下列命令恢复教学，服务保持停止，当前程序与文件按现有恢复机制保留。

```powershell
& 'C:\Program Files\WCCS-Image\package\runtime\pwsh.exe' -NoProfile -File 'C:\Program Files\WCCS-Image\package\scripts\client-field.ps1' -Action Recover -Target 'C:\Program Files\WCCS-Image-State\target.json'
```

- 若出现账户所有权、SID、DPAPI 或目录冲突，保留失败状态和现场证据，检查所分发镜像是否包含完整账户与用户配置文件，再重新分发已验证镜像。
- 断网恢复继续撤销本轮限制并保留会话与文件。重新联网后需要新的明确管理操作才能启用比赛控制。

## 两台机器的首次核验

对两台不同机器名的代表机分发测试镜像，核对各自名称、不同凭据和服务端记录。批准接入并完成普通账户登录后，确认选手无需经过首次欢迎和配置。分别断网、重新联网，再重启触发 C 盘复原，核对回到原设备、旧凭据失效、教学可用和旧比赛指令未恢复。将实际结果和失败项记录到路线图，后续继续补齐项目功能与整体验收。
