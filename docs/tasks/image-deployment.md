## 实现与入口

### 母机

`image-mother.ps1` 提供升级、启动、诊断、教学恢复和封装，核对包内明确的 503-41 机器名与 MachineGuid。客户端、运行时、测试 CA 和统一配置随一个 ZIP 交付。使用现有 `client-field.ps1`、`client-system.ps1`、服务和 Provider 入口执行系统操作。

工作人员在管理端使用已有比赛账户页面触发受控登录，结束教学会话沿用预览和明确确认。真实会话探测验证 SID、活动默认桌面和 Windows Shell，等待首次初始化，成功后持久保存桌面准备及工具路径。随后使用三项维护模板准备桌面、工作目录和脚本，完成后恢复教学。

Seal 恢复教学、验证恢复账户、普通账户所有权、已准备桌面、工具访问与用户配置文件，导出管理员/SYSTEM 私有账户模板。模板清除机器绑定、旧命令、会话与序号，保留完整镜像内 SAM、SID 和 DPAPI 对应关系。旧版公共支持包一并保存，现有工具完整路径继续有效。卸载服务与 Provider 后清除专用安装目录和启动状态目录，目录外持久清理记录支持中断后继续。部分公共包复制使用独立 staging 目录和完整摘要检查。

封装检查限制载荷目录和模板 JSON 字段，拒绝混入设备令牌、逐机回执、旧命令及其他材料。母机外部另存的旧注册包、测试压缩包、原始诊断和回收站副本需要工作人员统一清理。账户配置文件、工作目录与工具保留在完整系统镜像中。

### 克隆与复原

开机 SYSTEM 任务调用 `image-deployment.ps1 -Action Boot`。实际系统名来自操作系统 API，独立于复制的 JSON、环境变量和 MachineGuid。大写机器名的 SHA-256 前 32 个十六进制字符形成稳定关联号，随机注册材料原子落盘，设备令牌由现有客户端生成。同一启动状态重复执行复用材料，C 盘复原后生成新凭据并关联同名设备。

Boot 安装客户端、CA 和公共配置，恢复支持包，验证普通账户配置文件、SAM 所有权、普通权限、恢复认证与工具访问，导入账户模板并注册 Provider。导入配置最后发布，避免服务读取半成品。启动进度记录在 `C:\Program Files\WCCS-Image-State\status.json`，失败后任务计划程序重试，现场修复后可再次运行该任务。

服务器离线或注册窗口关闭时客户端自动重试，教学正常使用。账户模板、工具恢复和服务启动失败可随注册请求显示固定失败阶段。安装尚未完成且无法联网报告时保留本地状态。日志和公共错误信息使用固定代码。

### 管理端

迁移 013 保存镜像申请，管理页面“注册审核”增加镜像批量审核。管理员核对机器名、本次与原来源 IP、旧设备在线状态、竞争申请和初始化失败阶段，再批准或拒绝。相同请求重试、窗口关闭后的既有申请、过期申请重新审核均使用原材料。批量审核使用管理员鉴权、CSRF、生命周期版本和事务去重。

批准更新设备凭据代次，撤销旧凭据和旧控制/维护命令，保留同一镜像设备记录与座位计划，要求重新核对地址。禁用设备保持禁用。旧设备仍在线、初始化失败或同批选中同名多份申请时拒绝整个操作。首次从旧逐机部署切换到镜像关联号需要管理员重新绑定座位，原历史仍保留。

网络恢复和接入批准均不会自动启用比赛限制。工作人员在比赛账户页面重新预览并触发登录，再按需要执行等待或维护。教学恢复继续使用已有管理页面和本机恢复入口，保留当前会话及文件。
