## 本轮实现

- 白底与灰色表面、蓝色主操作、直角控件和密集表格，规范见 [界面规范](../ui-design.md)。字体采用仓库现有离线资源和系统中文字体。
- 地址入口采用 `#/seats`、`#/devices`、`#/targets`、`#/rooms`、`#/configuration`，兼容已有 `#rooms` 等书签。默认进入座位总览。
- 座位总览显示座位数、唯一绑定数、未绑定数、冲突数和覆盖率。搜索与状态筛选支持网格和列表，点击座位查看物理位置、稳定 ID、地址来源和工具结果。
- 设备页展示连接、位置、观察 IP、期望 / 实际版本与检查状态。支持名称排序、在线 / 离线 / 待注册 / 未分配 / 冲突筛选，详情继续支持真实工具重查。
- 检查任务页和座位页共享目标选择。机房编辑器、座位页和检查任务页复用同一个服务器预览 / 提交组件。提交保留后端鉴权、基准版本、请求去重及逐项跳过。
- 页面切换保留编辑草稿和筛选，导航返回页面顶部。登录代次隔离和刷新序号阻止旧会话或过时请求覆盖当前状态。
- 本轮使用现有依赖，Rust / PostgreSQL API 契约由上一切片提供。
